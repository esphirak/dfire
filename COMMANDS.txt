7. COMMON ERRORS AND FIXES
--------------------------
"python is not recognized"
    -> You forgot to activate (section 1), or Python isn't installed (section 6b).

"yolo is not recognized"
    -> Activate first (section 1).

"Fatal error in launcher: Unable to create process"  (happens after renaming/moving the project folder)
    -> python -m pip install --force-reinstall --no-deps ultralytics

"Fatal error in launcher" when running pip
    -> Same cause. Use  python -m pip install ...  instead of  pip install ...
       Or repair pip once:  python -m pip install --force-reinstall pip

"No such file or directory: models\yolo_stage2\best.pt"
    -> The model is missing or misnamed. Check with:  Test-Path models\yolo_stage2\best.pt
       Find it with:  Get-ChildItem -Recurse -Filter best.pt | Select-Object FullName

"... .jpg does not exist"
    -> The photo isn't there. Check the folder name (test vs train) and the file name.

"Could not open video source"
    -> Wrong camera number (try --source 1 or 2) or wrong video path.

The video window is cut off
    -> Use --display-height 600 (smaller) or resize the window with the mouse.

Nothing happens when pressing Q
    -> Click on the video window first, then press Q.
